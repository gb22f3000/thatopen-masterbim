# 03 — User Guide

## Sign in

1. Open the app → `/login`
2. Choose **User** or **Admin** tab (pre-fills username)
3. Enter password → **Sign in**

## Projects

- Search, open cards, create **New project**
- Admin also gets **Import / Export** JSON
- Users only see projects they own (plus demos without `ownerId`)

## Project workspace

Left: dashboard + to-dos  
Right: 3D viewer

### Viewer backgrounds (View BG toolbar)

Dark · Sky blue · Mist · White

### Workspace theme (sidebar)

Dark · Sky · Light

### Models

Demo Model · Load IFC · Convert IFC→frag · Import/Export .frag

### Measure

- Length: double-click start + end
- Area: double-click ≥3 points → **Enter**
- Esc cancels

### Log out

Sidebar **Log out** clears the session and returns to `/login`.
